## 1. 页面信息架构

| 区块 | 职责 |
|---|---|
| 顶栏 | 标题/副标题（“当前加载 N 个教学班，M 个课组”）、导出课程、打开智能选课助手、重读 course.json |
| 课表预览（主区） | 周课表网格 + 方案切换（上一/下一、页码、显示此方案、返回原课表）+ 汇总 chips |
| 现有课表（右栏） | 一键导入班级/个人 JSON、导出当前/目标课表、导出截图、清除底板、底板摘要 |
| 课程查询（右栏） | 搜索 + 按课组分组的教学班列表（加入/移除） |
| 已选课组（右栏） | 课组卡片、教学班 pill（底板/锁定标记、锁定/删除） |
| 约束与候选（下部） | 课程级/时间级/方案级约束、估算、生成、候选列表（分页/收藏/删除/收藏夹/预览/返回） |

## 2. 视觉审计（几何证据）

- 桌面 1440px：**顶栏三按钮同高 43px（差值 0）、同 y=14 对齐**；全页无横向溢出、无控件出视口；
  周课表 84 格正常渲染。整页高 2639px，布局自上而下完整。
- 移动 390px：顶栏按钮折叠为竖排且同高 44px；周课表在 `.timetable-scroll` 滚动容器内横向滑动
  （min-width 748px，属设计而非缺陷）；无控件出视口。
- 视觉弱项（已修）：候选工具栏按钮较多 → 移动端已改为**候选工具栏粘底**（sticky bottom）；
  约束自定义表单桌面 4 列一行、窄屏 1 列；顶栏按钮 ≥761px 不折行；
  移动端整页很长的问题主要靠候选工具栏粘底缓解（生成/估算仍在大区顶部）。

## 3. 使用逻辑审计

按用户真实动线走查，逐项结论：

- 数据加载：`loadCourses()` 拉取课程 → `autoImportPersonalSchedule()` 自动底导入并锁定
  → 旧锁定迁移 → 恢复候选。行为正确、有失败兜底（bootstrap catch）。
- 课程查询与分组：`filterCourses` + `groupCourses` 按课组聚合。
  - **问题1（本页核心缺口，已修）**：默认每课组只渲染前 5 个教学班（`items.slice(0,5)`）且
    **没有任何“查看全部”入口**。遇到一门课 6+ 个教学班，用户从列表根本看不到第 6 个及以后，
    只能靠精确搜索。已加“查看全部 N 个教学班 / 收起”按钮；探针验证 5→7、文字切换正确。
  - **问题2（已修）**：搜索输入**无防抖**，4449 门课场景每次敲键全量重建列表，明显掉帧。
    已加 180ms 防抖。
- 选课/锁定：课组内多教学班可选其一，可锁定（锁定=该课组定死不换）；底板自动锁定；冲突
  提示（时间冲突/同课程号）在已选项上明确标红。逻辑清晰，做得好。
- 约束：课程级（学分/排除教师/锁定/关联）＋时间级（早八/午间/晚课/全天无课）＋方案级
  （强制一起/教师一致）。估算/生成走 Worker，Worker 不可用自动降级同步；0 方案时给出原因诊断。
- 候选浏览：分页/预览/返回/收藏/删除。**删除与恢复**此前“恢复=全量重算”，已改为“本轮快照
  撤销”（A4，恢复不重求解、保持顺序）。生成超 500 的确认已改应用内弹层（A5）；失败有横幅+重试（A6）。
- 导出/导入：导出按“预览中→目标课表 / 非预览→当前课表”动态命名并落盘；支持导出截图；
  导入底板记录未匹配条数、清空会连带解锁。**已做成的好设计**：subtitle 明确“教学班/课组”双口径、
  `candidatePreviewEnabled` 联动导出文案。
- 持久化：状态写 `localStorage('hdu-scheduler-state-v3')`，刷新/重开可恢复；候选/收藏/删除均有
  持久化字段。

## 4. 结论

该页功能完整、主体对齐良好，没有破坏性 bug；本页专属可感知问题（超 5 教学班不可见、搜索卡顿）
已修复并验证；P3 视觉/操作整理项（顶栏不折行、约束表单列数、候选工具栏粘底、导入未匹配明细）
也已全部落地（v0.5.13）。
